# hardware-store-app

A Desktop App for a Hardware Store using Electron framework. These are the functionalities for the MVP:

    Product registration
    Customer registration
    Cash register opening
    Cash register closing
    Simple sale
    Simple payment
    Automatic stock reduction
    Low stock check
    Basic reports
    Manual backup

Tech stack used:

    Electron
    React
    Vite
    TypeScript
    SQLite
    Drizzle ORM
    Zod
    Tailwind CSS
    Electron Builder
    Git/GitHub
